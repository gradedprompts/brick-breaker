# Brick Breaker

A browser arcade game in one HTML file, built by a single prompt on Claude Code (Fable 5.1).

Play it: https://gradedprompts.github.io/brick-breaker/

`index.html` is the unedited output of one run of the prompt. Nothing was changed by hand after the run.

SHA-256: `928219f324ace97414c81f23afad78aec5c773af1a03767f909160ba31d58fa2`

The prompt that builds it is free on Graded Prompts: https://www.gradedprompts.com/prompts/apps

How to play: move the paddle with the mouse, touch, the arrow keys or A and D. Click, tap or press Space to launch the ball. P pauses, M turns the sound on or off. Three levels, a saved high score, and it runs offline from a double-click on the file.

Running the prompt yourself gives the same game as this one; visual details vary between runs.
